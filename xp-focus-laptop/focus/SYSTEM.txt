MY FOCUS SYSTEM - one page
==========================

ONE-TIME SETUP (in the Cygwin terminal)
      echo "alias focus='python C:/focus/focus.py'" >> ~/.bashrc
  Close and reopen the terminal. From then on, from any folder:

TO START A DAY
      focus
  Then follow it. It asks the questions and writes the files.

OTHER COMMANDS
  focus done      tick off a finished task, no pomodoro needed
  focus extra     record a pomodoro you did away from the script
  focus today     ONE PAGE FOR TODAY: the MUST, what is done, what is left
  focus dash      dashboard only        focus summary   recap of a cycle
  focus pomo      timer only            focus points    size one task
  focus undo      take back a mistake   focus backup    copy to USB stick
  focus check     daily routines (shower, meals ...): tick them off
  focus matrix    the Eisenhower chart, to look at or re-sort
  focus practice  the uncertainty / failure / conflict ladders
  focus appt      today's fixed things (work, the vet)
  focus reward    your reward menu
  focus report    which questions you answer and which you skip
  focus sync      pull notes from the PSPi into the parking lot
  focus help      list of commands      (add --help to any for details)

WHAT day.py DOES, IN ORDER
  1. Shows your progress dashboard.
  2. Counts the focus day (D1, D2, ...). These are its own count, so you
     can start on any workbook page. It notes the workbook page if you
     tell it.
     It has no clock. If the last day is unfinished it offers to
     continue it. If the last day is finished it asks "Is this a new
     day?" - a new day starts only when you type y.
  3. Day 1 of each 7-day cycle: cycle planning (see below).
     Other days: asks if there is anything new to add to the backlog.
     Then the Eisenhower chart: all open tasks in their four boxes.
     Type a number to re-sort one, or Enter if it is right.
  4. Shows the NEXT note you left last time.
  5. You pick today's MUST and promise a number of pomodoros.
  6. For each pomodoro: you say what you will do, the timer runs,
     then it asks how it went (3 focused, 2 okay, 1 scattered,
     0 abandoned = does not count) and what comes NEXT.
  7. For each break: you say what you will do away from the screen,
     the break timer runs, then it asks if you really stepped away.
  8. At the promised number it stops you, asks if the MUST is finished,
     and shows the dashboard again. Close the laptop.
  9. Day 7 of a cycle: a short review, then back up C:\focus.

HELPERS BUILT IN
  Parking lot   A stray thought mid-pomodoro goes into park.txt (keep it
                open in Notepad++), or answer the "stray thought" question
                after the pomodoro. At the end of the day, day.py goes
                through them: add to backlog, drop, or keep parked.
  Energy        day.py asks 1 low, 2 normal, 3 high. On a low day it
                suggests ONE pomodoro, and that is a full win.
  First step    Before each pomodoro it asks for the first two-minute
                action. Start with that, nothing bigger.
  Deadlines     For an urgent task, day.py asks "due in how many focus
                days?" and writes it as @D20. The dashboard lists the
                nearest ones, red when 2 days or fewer are left. These
                are focus days, not calendar days - keep real dates on
                paper too.
  Undo          focus undo removes the last log line or moves the last
                finished task back to DOING.
  Backup        focus backup copies everything to focus-backup on the
                USB stick and writes progress.json for the Mac.
  Celebration   When the promise is kept: a short tune and a few seconds
                of confetti. celebrate=off in settings.txt turns it off.
  PSPi notes    On the PSPi type  note buy stamps . Later, with the PSPi
                plugged in,  focus sync  moves the notes into park.txt.
                Setup steps are in pspi\README.txt.
  Routines      Things that recur every day (shower, meals, meds) are NOT
                tasks. List them in routines.txt, one per line; add x3 for
                three times a day. Tick them with  focus check , or when
                day.py shows the list at the start and end of the day.
                Boxes start empty again on each new focus day.
                Each routine shows its streak: focus days in a row on
                which it was fully done, and your best so far.
  Appointments  Every day it asks for anything fixed with a time (a work
                shift, the vet). They show at the top of the day page and
                above each pomodoro. They are not tasks. The laptop has no
                clock, so set a phone alarm for each.
  Rewards       rewards.txt is a list of things you enjoy. When the day's
                promise is kept, one is suggested at random.
  Report        focus report counts which optional questions you answer
                and which you skip, and names the settings.txt line that
                switches a skipped one off (for example ask_first=off).
  Pick for me   When choosing the MUST is too much, type p. It takes the
                top item.

THE DASHBOARDS
  focus today     today only: fixed things, the MUST, your promise,
                  routines, practice, what is done and what is left
  focus dash      the big picture on ONE screen, one line per area
  focus dash all  everything in full: the pomodoro wall, milestones,
                  the activity grid, routines, practice, velocity, goals
  focus summary   one cycle looked back on
  day.py shows the one-screen dashboard at the start, and the day page
  followed by the one-screen dashboard at the end.

THE TIMER
  No numbers. Six designs, chosen at the start of each day:
    hourglass  sand runs down          candle  burns down and goes out
    ball       box fills from below    sun     crosses the sky and sets
    snake      winds until box is full rocket  climbs to the moon
  "Surprise me" uses a different one each day.
  Preview one for 25 seconds:   focus pomo rocket demo
  The work colour changes each day (yellow, cyan, magenta).
  Green is always a break.
  One soft beep = halfway: are you still on the task?
  Three beeps = time.
  Ctrl+C stops it; that pomodoro does not count. Run focus again
  and it offers to continue the same day.

ADDING A TASK (day.py asks; this is what the questions mean)
  Urgent?  Important?   -> the four Eisenhower boxes
    1 urgent + important     -> top of THIS CYCLE
    2 important only         -> BACKLOG - IMPORTANT  (the real work)
    3 urgent only            -> BACKLOG - SOMEDAY
    4 neither                -> dropped
  Four size questions        -> story points 1, 2, 3, 5 or 8
    Anchor: re-solve one LeetCode problem = 2 points.
    8 = too big, split it before starting.
  Goal word (hsk, cs311...)  -> adds #hsk so the dashboard can chart it

CYCLE PLANNING (day 1 of each cycle)
  Sort what is on your mind on paper first. Then day.py shows your
  velocity (points finished per cycle), returns leftovers to the
  backlog, and lets you pull tasks into THIS CYCLE until it is full.
  First cycle: 8 to 10 points.

PRACTICE LADDERS (focus practice)
  Three ladders - uncertainty, failure, conflict - for one skill:
  tolerating an outcome you cannot control or do not like. Five rungs
  each. Aim for one small rep per ladder per cycle.
    Plan   what you will do, and what you are afraid will happen.
    Do it  feel the discomfort, do not escape, do the next action.
    Log    what you did, what you felt, the outcome, whether the feared
           thing happened, how hard it was, whether you used the escape.
  Move up only when a rung feels boring; the script offers it after two
  boring reps in a row. Moving down or skipping a cycle is fine.
  day.py offers to plan the reps on day 1 of a cycle and asks at the end
  of each day whether you did one. ask_practice=off stops both.
  You set the pace. Show this to your therapist.

CHECKING BACK IN WITH CLAUDE
  focus feedback   jot a note about the system the moment it annoys or
                   helps you. It goes into feedback.txt.
  focus diagnose   writes diagnose.txt: version, settings, numbers, which
                   commands you run, which questions you skip, any
                   crashes, your feedback, and the recent log.
  If the script ever crashes, the details go to errors.txt by themselves.
  Then  focus backup , and bring the USB stick to the Mac.

RULES
  - A promise is about time. "Planned 2, did 2" is a win even if the
    task is not finished.
  - Doing more than planned breaks the promise too.
  - First cycle: 2 pomodoros a day. Raise it by one only after a whole
    cycle of kept promises.
  - Breaks happen away from the laptop.

FILES (all in C:\focus)
  focus.py and the other .py files are the programs.
  backlog.txt  tasks (you can edit it by hand in Notepad++)
  log.txt      everything that happened (written for you)
  today.txt    today's plan and NEXT note (written for you)
  park.txt     parking lot for stray thoughts
  routines.txt daily routines and how many times a day
  rewards.txt  your reward menu
  settings.txt timer style and lengths, screen width
  Keep the section names in backlog.txt exactly as they are.
